# AGV API 控制模块快速上手指南

## 🚀 快速开始

### 1. 启动服务

**后端启动**:
```bash
cd manager/springboot
mvn spring-boot:run
```

**前端启动**:
```bash
cd manager/vue
npm install
npm run serve
```

### 2. 访问控制面板

浏览器访问：`http://localhost:8080/agv-control-panel`

或在左侧菜单中点击 **"AGV 控制面板"**

---

## 📋 使用步骤

### 步骤 1: 连接 AGV

1. 进入 **AGV 监控** 页面 (`/agv-monitor`)
2. 点击 **连接** 按钮，输入 AGV 的 IP 和端口
3. 确保 AGV 状态显示为 **"已连接"**

### 步骤 2: 选择 AGV

1. 进入 **AGV 控制面板** 页面
2. 在下拉列表中选择已连接的 AGV
3. 系统会自动显示 AGV 的 IP 和端口信息

### 步骤 3: 发送命令

#### 方式一：快捷命令（推荐新手）

直接点击按钮发送常用命令：
- 🔍 **查询状态** - 获取 AGV 当前状态
- 📍 **获取位置** - 获取 AGV 当前位置坐标
- 🛑 **紧急停止** - 紧急情况下使用
- 🔄 **系统复位** - 重置 AGV 系统
- 🔌 **充电** - 发送充电指令
- ❌ **取消任务** - 取消当前执行的任务

#### 方式二：坐标移动

1. 在 **坐标移动** 区域输入目标坐标
   - X 坐标：例如 `15.0`
   - Y 坐标：例如 `4.0`
   - 角度：例如 `1.5707963` (约 90 度)
2. 点击 **发送移动命令**

#### 方式三：标记点移动

1. 在 **标记点移动** 区域输入标记点名称
   - 例如：`work_station_1`, `charging_point` 等
2. UUID 可留空（系统自动生成）
3. 点击 **发送到标记点**

#### 方式四：自定义命令

1. 输入 API 路径，如 `/api/custom_command`
2. 输入参数，格式：`key1=value1&key2=value2`
   - 例如：`location=15.0,4.0,1.5707963&speed=0.5`
3. 点击 **发送自定义命令**

## 📊 查看响应

所有 AGV 返回的数据都会显示在 **响应日志** 区域：

### 日志类型说明

- **蓝色条目** - 你发送的命令
- **绿色条目** - AGV 返回的成功响应
- **红色条目** - 错误信息
- **灰色条目** - 系统消息（如 WebSocket 连接状态）

### 日志内容包含

- ⏰ 时间戳（精确到毫秒）
- 📝 命令类型
- ✅ 执行状态
- 📦 详细数据（JSON 格式）

## 🔍 示例场景

### 场景 1: 查看 AGV 状态

```
1. 选择 AGV_001
2. 点击 "查询状态"
3. 查看日志中的响应数据
```

**预期响应**:
```json
{
  "battery": 85.5,      // 电量 85.5%
  "speed": 1.2,         // 速度 1.2 m/s
  "position_x": 10.5,   // X 坐标
  "position_y": 5.3,    // Y 坐标
  "status": "working",  // 工作状态
  "error_code": 0       // 无错误

```

### 场景 2: 移动到指定位置

```
1. 选择 AGV_001
2. 在坐标移动区域输入:
   - X: 15.0
   - Y: 4.0
   - 角度：1.5707963
3. 点击 "发送移动命令"
4. 等待 AGV 响应
```

**预期响应**:
```json
{
  "code": 200,
  "status": "success",
  "message": "移动命令已接收",
  "type": "move_result",
  "data": {
    "success": true,
    "target_location": "15.0,4.0,1.5707963"
```

### 场景 3: 紧急停止

```
1. 选择任意 AGV
2. 点击 "紧急停止" 按钮
3. 确认 AGV 立即停止运动
```

⚠️ **注意**: 紧急停止仅在紧急情况下使用，正常情况请使用 "取消任务"

## 🛠️ 高级功能

### WebSocket 实时推送

系统会自动通过 WebSocket 推送 AGV 响应：

- **连接地址**: `ws://localhost:8080/ws/tcp-status`
- **自动重连**: 断线后 5 秒自动重连
- **实时性**: AGV 响应会在 100ms 内推送到前端

### 自定义 API 扩展

如果你的 AGV 支持自定义 API，可以这样使用：

```
API 路径：/api/set_speed
参数：speed=0.8&acceleration=0.5
```

这会发送：`/api/set_speed?speed=0.8&acceleration=0.5` 到 AGV

---

## ⚠️ 注意事项

1. **连接检查**: 发送命令前确保 AGV 已连接
2. **紧急停止**: 谨慎使用紧急停止按钮
3. **坐标范围**: 确保目标坐标在地图范围内
4. **网络延迟**: 如果响应慢，检查网络连接
5. **日志清理**: 定期清空日志避免内存占用

## 🐛 常见问题

### Q1: 提示 "AGV 未连接"
**解决**: 
- 检查 AGV 是否已连接
- 在 AGV 监控页面重新连接
- 检查 IP 和端口是否正确

### Q2: 发送命令后没有响应
**解决**:
- 检查 WebSocket 是否连接成功
- 查看后端控制台日志
- 确认 AGV 服务端正常运行

### Q3: 日志显示解析失败
**解决**:
- 检查 AGV 返回的 JSON 格式是否正确
- 查看原始响应数据
- 联系 AGV 服务端开发人员

### Q4: WebSocket 频繁断开
**解决**:
- 检查网络连接稳定性
- 重启后端服务
- 清除浏览器缓存
